# Complete DevOps Pipeline

## Overview

This project demonstrates a complete end-to-end DevOps pipeline for building, testing, containerizing, deploying, and monitoring a Node.js application using modern DevOps tools.

## Technologies Used

* Git
* GitHub
* Node.js
* Express.js
* Docker
* Jenkins
* AWS EC2
* Prometheus
* Grafana
